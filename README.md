# Global equity backtest website

**Live website:** https://krizknowz.github.io/global-equity-site/

Interactive performance, monthly drawdowns, holdings, trades, risk details, and downloadable CSV/ZIP records.

This website presents the audited research snapshot `20261016T005025953083Z_factor_neutral`. It is a historical simulation, not live account performance.

The `gh-pages` branch contains the published static website and its exports. This repository contains no research source code, raw provider datasets, account credentials or database settings.
